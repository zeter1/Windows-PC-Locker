# Поддержка и сообщения об ошибках

Для проблем Windows PC Locker особенно важны версия Windows, настройки питания и точная последовательность блокировки/разблокировки.

Полезно приложить:

- версию программы;
- версию Windows;
- настройки таймера, предотвращения сна, предотвращения выключения монитора и автоотключения после разблокировки;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- безопасное содержимое `last_problem.json`, `diagnostic_context.json` или небольшой релевантный фрагмент лога.

## Безопасная базовая проверка

Перед созданием issue можно выполнить:

```powershell
python computer_locker.pyw --self-test
```

Самотест не должен блокировать компьютер и не предназначен для изменения пароля/PIN или Windows-аутентификации.

## Приватность

Перед публикацией диагностики удалите личные пути и другие чувствительные данные. Приложение использует стандартный Windows lock screen и не хранит пароль или PIN пользователя.

Обычные ошибки можно сообщать через GitHub Issues. Потенциальные уязвимости — по правилам из [`SECURITY.md`](SECURITY.md).
