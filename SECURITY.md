# Security and privacy

Windows PC Locker использует стандартные Windows API для блокировки сеанса и управления режимом предотвращения сна. Программа не хранит пароль или PIN и не заменяет стандартный экран аутентификации Windows.

## Сообщение об уязвимости

Если вы обнаружили проблему, которая может приводить к обходу ожидаемого поведения блокировки, неожиданному системному действию, небезопасной обработке локальных настроек или раскрытию данных, не публикуйте чувствительные детали в открытом issue до предварительного контакта.

Связь: **zeter11@gmail.com**

## Граница ответственности

Приложение:

- вызывает стандартный `LockWorkStation`;
- может временно использовать `SetThreadExecutionState` для предотвращения сна;
- отслеживает состояние сеанса через Windows API;
- не управляет паролем, PIN, Windows Hello или другими средствами аутентификации.

За безопасность входа после блокировки отвечает Windows.

## Диагностические данные

`diagnostic_context.json`, `last_problem.json` и ротируемые логи могут содержать технические сведения о системе и локальные пути. Перед публикацией проверьте их содержимое и оставьте только данные, необходимые для воспроизведения проблемы.

## Настройки

Не редактируйте рабочие настройки во время активного системного сценария без резервной копии, если вы исследуете проблему. Для безопасной проверки API используйте встроенный `--self-test`, который не блокирует компьютер и не включает режим предотвращения сна.
