# Документация Windows PC Locker

Единственный обзор проекта — [корневой README](../README.md): назначение, готовая Windows-сборка, запуск из исходников, параметры питания, настройки, диагностика и безопасный self-test.

- [AGENTS.md](../AGENTS.md) — правила работы с исходниками и ограничения проверки системных действий.
- [SUPPORT.md](../SUPPORT.md) — данные для сообщения об ошибке.
- [SECURITY.md](../SECURITY.md) — сообщения об уязвимостях.
- [CHANGELOG.md](../CHANGELOG.md) — принятые изменения.

Правила упаковки находятся в `build_exe.bat` и `tools/build_windows.ps1`. Self-test не подтверждает работу в интерактивном пользовательском сеансе.
