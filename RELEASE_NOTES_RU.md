# Изменения Windows-сборки

- Готовый `Windows-PC-Locker.exe` теперь публикуется как постоянный GitHub Release.
- В релиз также входит portable-архив `Windows-PC-Locker-portable-x64.zip`.
- Для опубликованных файлов доступен `SHA256SUMS.txt`.
- Перед публикацией CI запускает safe self-test, собирает onefile EXE и проверяет self-test уже packaged-бинарника.
- README теперь прямо указывает, где скачать готовую Windows-версию.

## Проверка

CI проверяет WinAPI-контракты безопасным способом без реальной блокировки runner. Реальное поведение блокировки/разблокировки интерактивной Windows-сессии и энергосбережения требует проверки на целевом компьютере.
