# Правила работы с Windows PC Locker

- Обзор, запуск, данные и проверки описаны в [README.md](README.md); [docs/README.md](docs/README.md) ведёт к этому единственному обзору.
- `computer_locker.pyw` владеет поведением приложения. `build_exe.bat` вызывает `tools/build_windows.ps1`, который владеет упаковкой Windows EXE.
- Программа использует стандартную блокировку Windows. Не заменяйте её собственным экраном пароля и не храните учётные данные.
- Не проверяйте реальную блокировку или изменение питания на активном пользовательском сеансе без отдельного разрешения. Для автоматической проверки есть `--self-test`, описанный в README.
- Настройки и `Логи проблем/` — локальные данные пользователя; не включайте их в Git и не удаляйте при проверках.
- После принятой правки обновляйте `CHANGELOG.md`; отделяйте статические/self-test проверки от реальной блокировки, разблокировки и предотвращения сна.
